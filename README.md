# Web Privilege Escalation

## Project Overview
This project demonstrates web application security concepts related to privilege escalation and access control vulnerabilities. It explores how improper authorization checks can allow a user to access resources or functionality beyond their intended permissions.

The project was developed as a practical learning exercise to understand web application security, user roles, and common authorization weaknesses.

## Objectives
- Understand authentication and authorization in web applications.
- Explore privilege escalation through insecure access control.
- Demonstrate how improper authorization can expose restricted functionality.
- Learn security testing and mitigation techniques for web applications.

## Features
- User login and authentication.
- User dashboard and admin dashboard.
- Role-based access control concepts.
- Demonstration of authorization weaknesses in a controlled environment.

## Security Concepts
- Authentication vs. Authorization
- Insecure Direct Object References (IDOR)
- Broken Access Control
- Horizontal and Vertical Privilege Escalation

## Learning Outcomes
- Improved understanding of web application access control.
- Practical exposure to identifying authorization weaknesses.
- Understanding the importance of server-side permission validation.
- Awareness of security practices to prevent unauthorized access.

## Disclaimer
This project is intended for educational purposes and authorized security testing in a controlled environment. Do not test these techniques against systems without permission.
